**Fecha:** 2026-11-20
**Versión objetivo:** 1.0.12
**URL vigente:** https://headless-ovlafobmesc-apkcristianas-140d.wix-site-host.com/privacidad.html

El juego funciona sin cuenta. El apodo opcional, los tiempos, las estrellas y el progreso se guardan localmente. No se incorporan anuncios, analítica de seguimiento, compras ni sincronización con servidor propio. La RV1909 y los niveles funcionan offline. Android puede efectuar respaldo de datos de la aplicación bajo la configuración del sistema, porque el manifiesto actual admite respaldo; esto no constituye el servicio Google A6 de sincronización del producto. Datos locales se pueden eliminar con datos de aplicación o desinstalación (las copias del sistema siguen su política). Contacto: apkcristiana@gmail.com. Antes de incorporar autenticación Google, actualizar esta política conforme al funcionamiento realmente implementado.
